[RIGID-BODY CONTACT MECHANICS]

The Rocking-Block Stability Model

Real orbital boosters don't explode from bounding box overlap. Impact velocity tolerance and rotational center-of-mass stability are governed by decoupled physical laws.

FIGURE 1: FREE-BODY DYNAMICS & CRITICAL TIP ANGLE θ_tip = 25.6°
01 // IMPACT RESTITUTION (v_impact ≤ 63.0 m/s)

Touchdown kinetic energy is not a binary failure. Impacts below 63 m/s reflect with structural damping coefficient e = 0.4 and horizontal friction, reproducing dynamic rebounds before settlement.

02 // GEOMETRIC TOPPLE ANGLE (θ_tip = arctan(11/23) = 25.6°)

Derived directly from the landing gear baseline geometry (22m span, 23m center-of-mass height). If the tilt exceeds 25.6°, the gravity vector falls outside the footprint base polygon, driving irreversible angular acceleration into the ground.

03 // DYNAMIC FOOT PIVOTING & RCS AUTHORITY

When one landing gear contacts the deck first, the rocket enters a single-foot rocking state. The agent's RCS thrusters retain reduced authority (25%) to actively counter tipping moments before the rock timer expires.

Developer Command Center

# 1. Clone repository & install dependencies
$ git clone https://github.com/Mackming/hoverslam.git
$ cd hoverslam
$ python -m venv venv && source venv/bin/activate # or .\venv\Scripts\Activate.ps1 on Windows
$ pip install -r requirements.txt
# 2. Launch the all-in-one Pygame interactive dashboard
$ python launcher.py
Opens the graphical launcher to fly manually, watch agents, or scrub checkpoints.
# 3. Watch the flagship 3M-step master policy fly in real-time
$ python watch_agent.py
Defaults to `ppo_rocket_lander_v12_master/best_model.zip`. Press ESC to exit.
# 4. Train a brand-new PPO model with automatic vec-env benchmarking
$ python train.py --timesteps 2000000 --run-name my_hoverslam_run
Automatically benchmarks DummyVecEnv vs SubprocVecEnv on your CPU before starting.
