[SIMULATION FIDELITY]

Rigid-Body "Rocking-Block" Ground Contact

Most simple 2D landers judge touchdown as a binary bounding box collision. In real booster landings, structural integrity and rotational stability are completely decoupled.

01 // STRUCTURAL RESTITUTION

Impacts below 63.0 m/s are absorbed cleanly by the landing legs. Excess kinetic energy reflects with vertical damping coefficient e = 0.4 rather than terminating immediately.

MAX ABSORPTION: 63.0 m/s
CATASTROPHIC BLAST: 120.0 m/s
02 // GEOMETRIC STABILITY LIMIT

Derived directly from the landing gear geometry (22m foot span, 23m center-of-mass offset). An angle past 25.6° places the center of mass outside the base polygon, causing a committed topple under gravity.

TIP FORMULA: arctan(11 / 23)
CRITICAL ANGLE: ~25.6°
03 // FOOT PIVOT RESTITUTION

If one foot touches first, the booster pivots on that foot under gravity torque and cold-gas thruster correction. The rocket rocks dynamically before dual feet settle flat or tip over.

GROUND RCS FACTOR: 0.25
MAX ROCK WINDOW: 1.50 sec

Observation & Action Spaces

OBSERVATION SPACE: Box(9,) dtype: float32
IDX VARIABLE NORMALIZED BOUNDS PHYSICAL MEANING
0 Δx / (W/2) [-2.0, 2.0] Horizontal offset to moving pad center
1 Δy / (H/2) [-2.5, 2.5] Vertical altitude above pad landing deck
2 v_x / 10 [-20.0, 20.0] Horizontal linear velocity vector
3 v_y / 10 [-20.0, 20.0] Vertical sink velocity (negative = falling)
4 θ [-π, π] Pitch attitude angle (0 = upright)
5 ω [-8.0, 8.0] Booster angular rotation rate
6, 7 c_left, c_right [0.0, 1.0] Left / right landing gear contact flags
8 v_pad,x / 10 [-2.0, 2.0] Horizontal drift velocity of autonomous pad
ACTION SPACE: Box(2,) Continuous
  • action[0]: Main Engine Throttle [-1, 1] → [0, 1] (0 to 126.0 m/s²)
  • action[1]: Cold-Gas RCS Torque [-1, 1] (±12.0 rad/s² angular accel)
REWARD POTENTIAL FUNCTION
R = ΔΦ - 0.2·u_main - 0.05·|u_rcs| - 0.1

Terminal bonus rewards soft upright touchdown with +100 to +150 scaled by touchdown velocity and center offset. Crashes incur a strict -100 terminal penalty.

Developer Quickstart

# 1. Clone repository & install dependencies
$ git clone https://github.com/Mackming/hoverslam.git
$ cd hoverslam
$ python -m venv venv && source venv/bin/activate # or .\venv\Scripts\Activate.ps1 on Windows
$ pip install -r requirements.txt
# 2. Launch the all-in-one Pygame interactive dashboard
$ python launcher.py
Opens the graphical launcher to fly manually, watch agents, or scrub checkpoints.
# 3. Watch the flagship 3M-step master policy fly in real-time
$ python watch_agent.py
Defaults to `ppo_rocket_lander_v12_master/best_model.zip`. Press ESC to exit.
# 4. Train a brand-new PPO model with automatic vec-env benchmarking
$ python train.py --timesteps 2000000 --run-name my_hoverslam_run
Automatically benchmarks DummyVecEnv vs SubprocVecEnv on your CPU before starting.
